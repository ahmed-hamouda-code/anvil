How it works

Your first day, from an empty folder to a checked deploy

Six steps, all inside the window. Set up once, then repeat steps 3 to 6 for every Item.

You stay in control. Anvil prepares and checks; the deploy script is run by a person, never by Anvil.

  1. Set up once
  2. 1

    Workspace Your PC

    Make a workspace, then add a Folder for each functional area. It holds your work and your team's naming and checklist rules.

  3. 2

    Instances Once

    Add your instances and test the connection. The password is kept in Windows Credential Manager.

  4. For every Item
  5. 3

    Item Item editor

    Create an Item for each deliverable (a report, a package, an interface) and list its objects.

  6. 4

    Extract PC or apps server

    Bring the real objects in from the instance, straight from your PC or from the apps server.

  7. 5

    Validate & Drift Read-only

    Check the Item against your team's rules, and see whether an instance still matches what you have.

  8. 6

    Deploy & verify You run it

    Generate the deploy script, run it on the apps server, then register its log and let Anvil check the result.

Editions

One program, two editions

Without a licence key Anvil is the Standard edition. A signed licence key switches on Pro.

Standard
Free

Everything you need to bring one Item from instance to a checked deploy.

  • Workspace, Folders, Items and the item editor
  • Instances and the credential store
  • Extract database objects, and run the extract over SSH
  • Validate against naming and prefix rules
  • Generate a deploy script for one Item and register its log
  • Drift of one Item against one instance, on screen
  • Invalid objects, patching cycle check and Search
  • Overview, Problems, side-by-side Differences and the command palette

What's new

What's new in 1.1

  • Workspace Settings. One window for everything your team shares: Folders, naming, the checklist and, new in this version, the deploy options.
  • Splash screen. Anvil now opens with a splash screen showing the version and edition. You can turn it off in Settings.
  • Anvil themes. Two new looks in Anvil's own greens, one dark and one light. The light one is now the default.
  • Objects used by reports (Pro). For a report Item, Anvil reads its queries and data templates, finds the custom objects they use on the instance and lists them so you can add them to the Item.
  • Clearer messages. Message banners and field marks in every task window show what needs your attention.

Requirements

  • Windows 10 or 11, 64-bit.
  • Network access from your PC to the database.
  • For a database that enforces Native Network Encryption: Oracle Instant Client, 64-bit.
  • Optional: Git on your PC, for commits and the Git label.
  • Optional: an SSH login to the apps server, to run Extract on the server.

First run

The program is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click More info, then Run anyway. Checksums are in the zip and in the release notes, so you can check the download first.
